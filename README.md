# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 异常队列、现场复核、证据、复测评估和专业异议并存。
- 处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- JSON审阅包导出。

## 汛期调度令—异常—方案—应急联动 一致性接线

全库以单调递增的 `revision(R)` 作为一致性版本，看板、详情、审计与审阅包都取自同一快照：

- **调度令生效（原子级联）**：一次写入内完成旧令作废、受影响异常方案整体标记「失效待重算」（旧版归档 `plan.history`）、未完成任务一律「先停住」（带暂停原因）；已启动的应急联动**不回写、不撤销**，保留启动时锁定的调度令版本与级别，仅追加按新令复核要求（`levelPendingReview`）。
- **重算与恢复**：失效方案必须走「按现行调度令重算」，重算继承未完成（含已暂停）任务；新方案重新签批后才可逐项「恢复执行」。
- **两人签批同一异常**：提交时锁定依据（异常V/方案V），写入串行 + CAS——第一份通过，后到者发现依据已变即**保留草稿**，草稿写明打开时版本与当前版本的依据变化，同一异常只通过一份。
- **写入失败可恢复**：模拟失败后状态完全不动，写入进入持久化的「待恢复队列」（刷新仍在）；值班人员显式「恢复」时按入队顺序重放到最新快照并重新执行业务校验，任一笔失败即停止保留剩余，杜绝「联动已启动、方案仍旧版」的半成品。
- **同版展示**：看板、异常详情、审计和审阅包均带 `R版本` 标签；审阅包头部带 `consistencyTag`，包内不做跨版拼接。
- **关闭守卫**：仍有暂停任务、联动未按新令追加复核、方案未签批时不能关闭异常。

验证脚本（无需浏览器）：

```bash
node scripts/verify-seed.cjs     # 种子状态自洽性
node scripts/verify-engine.cjs   # 级联/并发签批/失败回滚/同版快照 共47项场景
```

界面顶部「模拟下一笔写入失败」演练失败保留与恢复；异常详情页「模拟并发会签」观察后到者落草稿。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
